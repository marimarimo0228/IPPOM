# 効果音の差し替え用フォルダ

効果音は初期状態では Web Audio でその場で合成しており、このフォルダは空でかまいません。

音声ファイルに差し替えたいときは、次の手順で行います。

1. 自作、または利用規約を確認したフリー素材の音声ファイル（mp3 など）をこのフォルダに置く。
2. `content/site.json` の `sounds` に、差し替えたい音のパスを書く。

```json
"sounds": {
  "tick": "/sounds/tick.mp3",
  "ippon": null
}
```

`null` のままの音は合成音が鳴ります。

| 名前 | 鳴る場面 |
| --- | --- |
| `tick` | 枠が1段点灯するたび（合成音は段ごとに音程が上がる。ファイルの場合は再生速度で音程を上げる） |
| `ippon` | 10点のとき |
| `oshii` | 9点以下で枠が止まったとき |
| `stamp` | 成績のハンコ（優・良・可） |
| `stampTop` | 成績のハンコ（秀） |
| `stampFail` | 成績のハンコ（不可） |

番組公式の効果音や曲は使わないでください。使った素材のクレジットは `content/site.json` の `credits` に追記します。
